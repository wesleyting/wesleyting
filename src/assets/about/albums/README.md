# About page album order

Album filenames use this format:

`album-<order>-<type>-<name>.<extension>`

- Change `<order>` to rearrange the carousel. The page sorts this number numerically.
- Use `cover`, `mockup`, or `padded` for `<type>`. CSS uses the type to compensate for empty canvas space while keeping the artwork visually consistent.
- Keep each order number unique.

Example: `album-2-padded-the-eminem-show.png`
